Data and privacy

Bring-your-own-key modes send your focus statement and limited public page metadata directly to the provider you choose. Hosted mode sends the same limited decision input to the Focus Guard service before it calls JEV.

Credentials and session state stay in this browser profile. Use narrowly scoped keys: browser extension storage is profile-local, not a system keychain.
